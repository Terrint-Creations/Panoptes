# Code of conduct

Panoptes is a community project and everyone taking part in it is expected to behave decently.

- Be respectful and patient, especially with newcomers.
- Criticise code and ideas, not people.
- No harassment, threats, slurs or personal attacks.
- **Never use Panoptes or this project's spaces to target someone.** Don't post other people's
  personal information, search results about private individuals or requests to investigate a
  specific person in issues, pull requests or discussions.

Maintainers may edit or remove comments, close issues and block people who break these rules.
Report problems by opening a private security advisory or by contacting the maintainers through the
form on [panoptes.terrint.com](https://panoptes.terrint.com/#join).
