Guide

Using Panoptes

This guide takes you from download to a finished case. If you only want the short version: install, type a username into the search bar, press Enter, and read the Overview.

Install

Panoptes runs on Windows 10/11 and Linux, and needs Python 3.11 or newer.

Windows

  1. Install Python from python.org. On the first screen of the installer, tick Add python.exe to PATH.
  2. Download Panoptes for Windows and unzip it into a folder you'll keep, for example Documents\Panoptes. Panoptes runs from this folder, so don't delete it afterwards.
  3. Double-click install.bat. It installs Panoptes and its optional extras, downloads the site databases, builds a small Panoptes.exe launcher and adds Desktop and Start Menu shortcuts.

Panoptes.exe is a tiny launcher for your installed Python, not a bundled interpreter, so antivirus software has nothing to object to. If you need Panoptes on a PC without Python, run install.bat portable to make a standalone build in dist\.

Linux

$ tar xzf panoptes-linux.tar.gz
$ cd panoptes-*/
$ ./install.sh              # desktop app and every optional capability
$ ./install.sh --minimal    # terminal tool only

The installer creates its own virtual environment in ~/.local/share/panoptes, links panoptes and panoptes-gui into ~/.local/bin and adds Panoptes to your applications menu. Nothing is installed system-wide. Run it again after downloading a newer release to update, or ./install.sh --uninstall to remove it (your cases are kept).

From source, any platform

$ cd Panoptes
$ python -m pip install -e ".[all]"
$ panoptes update

The extras are gui, email, phone, faces, ocr, ai and all.

Your first search

Open Panoptes and type into the search bar. Panoptes recognises what you typed:

You typePanoptes treats it as
jdoe42A username, checked on thousands of sites
jane@example.comAn email address
+1 202 555 0143A phone number (include the country code)
"Jane Doe"A person's name
example.com, 203.0.113.7A domain or an IP address
40.6892, -74.0445A location
A photo or documentA file: metadata, GPS, faces, text and reverse image search

Separate several targets with ;. If Panoptes guesses the wrong type, pick it from the type box or use all to try every reading.

Results stream in as each source finishes. A first quick pass shows the most likely accounts within seconds, then a thorough pass re-checks slow and blocked sites. Press Stop whenever you like: everything found so far is kept and summarised.

Reading a case

Overview

An identity summary built from every finding: likely real name, aliases, emails, phones, locations, accounts and an exposure score, with the sources that back up each value. Below it are insights rated by severity, such as leaked passwords or a home address visible in a photo.

Details

Every finding with its evidence. The confidence column matters:

  • 85% and up: strong. Confirmed by the site itself or by several independent sources.
  • 50 to 85%: likely, but worth checking yourself.
  • Below 50%: a lead or a guess. Panoptes lists it but doesn't follow it unless something else backs it up.

Each finding also shows what corroborated it and what conflicts with it. A profile whose real name contradicts the confirmed one is flagged so you don't merge two different people.

Graph

How everything connects, grouped by category. Click a node to inspect it. Right-click to run a new search from it, which extends the open case.

Cases and exports

Every search is saved automatically. Reopen old cases with File > Open saved case, and export them from the File menu as HTML (with the graph), JSON, CSV or STIX 2.1 for OpenCTI and MISP.

Full investigations

When you know several things about one subject, use Full investigation. Enter everything you have, names, usernames, emails, phones, domains, companies, places, wallets, files and notes, and choose which capabilities to run. Everything you enter is treated as confirmed, which lets Panoptes verify weaker findings against it.

The Capabilities menu turns individual techniques on or off: cooperative mode, face recognition, reverse image search, the alternate-account finder, site learning and the dark web.

Resources sets how hard Panoptes works your computer. Light uses fewer connections and a lower process priority so you can keep working, Heavy is the fastest. All three check the same sites and find the same results.

API keys

Panoptes works without any keys. Some free or paid keys unlock more data. Add them in Tools > Settings > API keys, or with panoptes config set NAME VALUE.

Settings lists every key with a link to where you get it. Keys can also be set as environment variables named PANOPTES_ plus the key in capitals.

Site logins

Some sites only show profiles to logged-in visitors. After a search, Panoptes lists the sites that blocked it. To include them, log in to that site in your browser with a burner account, copy the Cookie request header from the browser's developer tools (Network tab), and paste it into Settings > Logins & sessions:

$ panoptes login add linkedin.com "li_at=..."

Each cookie is only ever sent to its own site. Instagram, X and Reddit have dedicated fields with extra features.

Dark web and Tor

Dark-web search and onion audits need Tor. Panoptes uses, in order: a Tor proxy you set in Settings, a Tor that's already running (Tor Browser or the tor service), or its own private Tor instance. On Windows it downloads the official Tor Expert Bundle once from torproject.org. On Linux it uses the tor program from your package manager. Turn the dark web off with --no-darkweb or in Capabilities.

What leaves your computer

Panoptes has no account, no telemetry and no server of its own. Your cases, settings, keys and cookies are stored in ~/.panoptes on your computer. To search, it does contact the sites and services it checks, which means those sites see the searches. Two things to be aware of:

  • Reverse image search uploads local photos to Yandex. Turn it off with --no-reverse-image or in Capabilities.
  • AI image analysis sends photos to the provider you configured, only if you added a key.

Use a proxy or Tor (Settings > Network) if you don't want sites to see your IP address.

Terminal reference

$ panoptes search TARGET [TARGET ...]   # one or more targets, type auto-detected
$ panoptes investigate                  # interactive full investigation
$ panoptes sources                      # every source and whether it's ready
$ panoptes update                       # refresh the site databases
$ panoptes gui                          # open the desktop app
$ panoptes cases list | show N | export N FILE | delete N
$ panoptes config show | set KEY VALUE | unset KEY
$ panoptes login add SITE "COOKIE" | list | remove SITE

Troubleshooting

  • Few or no accounts found: run panoptes update to refresh the site databases, and check your connection or proxy.
  • Lots of "rate-limited" sites: use the Light profile, add API keys, or try again later. Some sites limit how often one IP can check them.
  • The desktop app won't start: run panoptes gui in a terminal to see the error. Logs are in ~/.panoptes/logs/panoptes.log (Tools > Open log folder).
  • Windows says Python isn't found: reinstall Python with Add python.exe to PATH ticked, then run install.bat again.

Still stuck? Open an issue on GitHub. Never include a real person's data in an issue.
