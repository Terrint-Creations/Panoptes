A hundred eyes on one question.

Give Panoptes whatever you know about a subject: a username, an email, a phone number, a name, a photo or a domain. It sends that to every technique that can say something about it, then merges what comes back, checks it against itself, scores it and follows the leads.

01 · The name

Named for the giant who never slept.

In Greek myth, Argus Panoptes was a giant covered in eyes. Hera set him to watch over Io because nothing could get past him: when some of his eyes closed to sleep, the others stayed open. His name means all-seeing.

No single OSINT tool sees everything. A username checker misses what a breach index knows, a breach index can't read a photo, and a photo tool has never heard of the company register. Each one has blind spots.

Panoptes puts them together. It is made of original code and of the ideas and data behind well known open source tools, rebuilt so they work as one. Where one eye is closed, another is open.

His head was ringed with a hundred eyes. Two at a time they took their rest, while all the others kept watch. Ovid, Metamorphoses I, paraphrased
02 · How it works

Not a launcher for other tools. One tool that thinks across them.

  1. Read the input

    Panoptes works out what you typed: a handle, an address, a number, coordinates, a file. Or you fill in everything you know.

  2. Fan out

    Every relevant source runs at once: thousands of sites, registries, breach indexes, maps, image and metadata tools.

  3. Merge

    Duplicate results from different techniques become one finding that lists everything that agreed on it.

  4. Verify

    Findings are cross-checked. Each gets a confidence score, and contradictions are flagged instead of hidden.

  5. Follow

    Trusted leads become new searches, so a new email or alias is investigated too. Guesses stay guesses.

Cooperative mode

Sources share what they learn. A fact is only used when you gave it, a source is very sure of it, or two independent sources agree.

Trust that is earned

A common first name or a generated username can't drag strangers into a case. Weak leads are listed but not followed.

One case, many views

An overview, per-finding evidence and a relationship graph. Export to HTML, JSON, CSV or STIX 2.1.

04 · Use it

Type what you know. Read what it found.

  1. Search. Type a username, email, phone, name, domain, IP or coordinates in the top bar, or drop in a photo. Panoptes detects the type.
  2. Or open a full investigation. Fill in everything you know about one subject and pick which capabilities to use.
  3. Watch it work. Findings stream in as each source reports. Stop at any time and you keep everything found so far.
  4. Read the case. The Overview sums up who the subject seems to be. Details shows the evidence for each finding. Graph shows how it all connects.

Every search is saved as a case you can reopen and extend. Right-click anything in the graph to search from it.

Use the Resources box to pick Light, Balanced or Heavy. Light keeps your computer responsive and still checks the same sites, just more slowly.

Read the full guide for settings, logins and tips.

# auto-detects the type of each target
$ panoptes search jdoe42
$ panoptes search jane@example.com -d 2 -o report.html
$ panoptes search "+44 20 7946 0958"
$ panoptes search photo.jpg

# everything you know about one subject
$ panoptes investigate --name "Jane Doe" -u jdoe -e jane@example.com --location Oslo

# saved cases, exports, settings
$ panoptes cases list
$ panoptes cases export 3 case.stix.json
$ panoptes config set hibp_api_key YOUR_KEY
05 · Download

Install in a couple of minutes.

Windows

Windows 10 or 11 · 64-bit · nothing else to install

  1. Unzip the download into a folder you'll keep, like Documents.
  2. Open Panoptes.exe for the desktop app, or run panoptes-cli.exe in a terminal.
  3. Optional: run Add shortcuts.cmd to put Panoptes on your Desktop and in the Start Menu.

Panoptes is new and unsigned, so Windows may say it protected your PC the first time. Choose More info, then Run anyway.

Download for Windows .zip

Linux

x86-64 · most distros from 2018 on · nothing else to install

  1. Unpack it: tar xzf Panoptes-linux-x64.tar.gz
  2. Start ./panoptes/panoptes-gui for the desktop app, or ./panoptes/panoptes in a terminal.
  3. Optional: run ./panoptes/install.sh to add it to your app menu and your PATH.

06 · Open source

Free today. Free forever.

Panoptes will never have a paid tier, a premium edition or a locked feature. It belongs to the people who use it and build it.

  • LicenseGNU GPL v3.0 or later. Use it, study it, change it and share it. Every published version stays open.
  • Fork itYou never need permission. Take Panoptes in any direction you want, under the same license.
  • ContributeSend issues and pull requests. Maintainers review each one, and some are accepted while others are declined or sent back.
  • PrivacyNo accounts, no telemetry, no cloud. Your cases and keys stay on your computer.
07 · Join

Become part of the project.

Anyone can contribute without asking: open an issue or a pull request on GitHub.

If you want a bigger role, like looking after a group of sources, reviewing pull requests, triaging issues or working on the docs and this site, ask to become a Panoptes project member here.

Membership is voluntary and unpaid. It may come with triage or write access to the repository.

Joining the Panoptes project does not make you part of Terrint Creations. It doesn't create employment, a partnership or any right to speak for Terrint. Read the governance notes.

Your request goes to the maintainers by email through FormSubmit. It is only used to answer you.

08 · Responsibility

Powerful tools need careful hands.

Panoptes only collects information that is already public, but putting it together can reveal a lot about a person. Only investigate people and organisations you have a legitimate reason and the legal right to look into: yourself, your own organisation, an authorised engagement, journalism or research with an ethical basis.

Never use it to stalk, harass, dox or intimidate anyone. Use burner accounts for site logins, and follow the laws and terms that apply to you.
