# Security policy

If you find a security problem in Panoptes itself (for example a way for a malicious website or
search result to run code, read local files or steal stored API keys and cookies), please report it
privately through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**.

Please don't open a public issue for security problems. We'll acknowledge the report, work on a fix
and credit you in the release notes if you'd like.

Reports about information Panoptes *finds* (for example "it found my old account") are not security
issues in Panoptes. Panoptes only shows what is already public. Remove the information at its source.
